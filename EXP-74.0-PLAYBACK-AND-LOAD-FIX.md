# Jahntella EXP 74.0

Install after EXP 73.1.

- Keeps the actual active Shine Era song and its playback position across a page refresh instead of reverting to Boots, Smile & Attitude.
- Restores paused/playing state when the browser permits resumed playback.
- Prevents the original player from overriding the extended Shine Era playback state.
- Caches the homepage shell for instant same-tab refreshes and uses browser caching for the initial shell request.
- Cache-busts the updated player files so the fix is used immediately after upload.

Extract into the repository root and allow the included files to overwrite their existing versions.
