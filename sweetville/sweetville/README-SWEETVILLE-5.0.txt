SWEETVILLE 5.0 — LIVING WORLD PATCH

This package contains only Sweetville patch files.
It does not include or modify the Jahntella homepage or magazine.

INSTALL
1. Upload sweetville/sweetville-v5-patch.css
2. Upload sweetville/living-world-v5-patch.js
3. Add these two lines inside sweetville/index.html:

<link rel="stylesheet" href="sweetville-v5-patch.css?v=5.0">
<script src="living-world-v5-patch.js?v=5.0"></script>

Place the stylesheet after sweetville.css.
Place the script before </body>.
