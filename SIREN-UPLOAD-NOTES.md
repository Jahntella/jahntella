# Complete Siren Era website update

This patch adds Album IV immediately after The Sparkle Era, all 11 song covers and MP3s, homepage Aesthetics artwork, Sweetville music cards, and one ordered 42-song playlist across all four albums.

## Upload
1. Download and unzip all three packages into the same folder.
2. Open https://github.com/Jahntella/jahntella on the main branch. Choose Add file > Upload files.
3. Drag the extracted files and folders (not the ZIP files or an extra enclosing folder) into the repository root. Preserve assets/album4 and sweetville paths.
4. Commit the files. If uploading in batches, upload assets/album4 first; upload the website code from package 3 last so new links only appear after the media is present.

All MP3s are unchanged copies. Art uses WebP originals and smaller thumbnails without cropping. Pretty Little Problem retains its portrait proportions.

## Verification
JavaScript syntax, audio metadata, MP3 byte checksums, cover/track mapping, all 11 album positions, homepage card and Aesthetics playback, next/previous and automatic album transitions, and Sweetville shared playback are checked locally. A browser visual preview was unavailable in this environment; verify desktop and mobile appearance after upload.
