JAHNTELLA WEBSITE — POSTER DOWNLOADS UPDATE

This package contains the complete eight-poster gallery, all poster files,
Jahntella's signature, responsive styling, and a safe installer.

EASIEST INSTALL (local copy / GitHub Desktop)
1. Copy every file and folder in this package into the ROOT of the jahntella repository.
   The root is the same folder that contains index.html, styles.css, and script.js.
2. Windows: double-click INSTALL-WINDOWS.bat
   Mac: double-click INSTALL-MAC.command, or run: python3 install_posters.py
3. Confirm index.html, poster-downloads.css, originals/, thumbnails/,
   web-previews/, and branding/ are committed and pushed to main.
4. Wait about 1–3 minutes for GitHub Pages, then hard-refresh the website.

WHAT THE INSTALLER DOES
- Preserves the rest of the existing website.
- Replaces only the current Downloads section.
- Keeps the three existing phone wallpapers below the new poster gallery.
- Adds poster-downloads.css to index.html.
- Creates index-before-posters.html as a backup.

IMPORTANT FOR GITHUB WEB UPLOAD
GitHub's website does not automatically run Python installers. If using only the
GitHub browser interface, first run this installer on your computer and then
upload the resulting changed index.html along with all included files/folders.

The poster paths intentionally match the folders already uploaded to the repo.
